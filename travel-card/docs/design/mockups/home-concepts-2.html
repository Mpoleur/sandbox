What changes in the App Style Sheet
  • New tokens: brand-navy #0B3D7A for the header (white text 10.7:1); the header has a 28 dp rounded bottom edge and a 52 dp pill search field, with the logo (44 dp) and the title Travel Cards.
  • New tokens category-border: Diet #E65100, Places #1565C0, Pets #6D4C41, Health #2E7D32, Transport #00796B, each at least 3.5:1 on white (note: Diet is darker than the earlier orange #F57C00, which was only 2.7:1). Used only as the ticket border, never as fill or text.
  • New component ticket replaces the card tile on Home: one per row, 84 dp high, 3 dp border, 80 dp symbol stub with dashed perforation and notches, label and a small source line. Card tile stays for the symbol picker and other screens.
  • New route rail: 2 dp dashed line #78909C, a stop dot (16 dp ring in the category colour) at each category header; Favourites uses a blue star as its stop. Favourite tickets carry a 22 dp blue star.
  • Trade-off: one card per row, so about two fewer cards per screen than the grid.
