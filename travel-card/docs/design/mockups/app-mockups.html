Travel Card: app style sheet highlights and 4 mock-ups

Working name. Approved by Matthieu on 23/11/2026. Android phone, one light look, display mode always white. Real SVG artwork from assets/symbols. Full style sheet: docs/design/App Style Sheet.md.

Feel: calm and quiet, so the signage-style artwork is the only strong colour. Neutral cool-grey screens, one blue for actions, 16 dp corners, no shadows except the add button, 48 dp minimum targets, the main action at the bottom for one-hand use.
