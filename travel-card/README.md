# Travel Card

A pocket set of "show this" cards for travellers. Each card says one important thing with symbols, a photo or translated text, and opens full screen in one tap, with or without internet.

"Travel Card" is the current working title. The final app name and logo are still to be decided.

## Status

Business Analysis in progress.
